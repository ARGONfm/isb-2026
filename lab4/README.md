# Лабораторная работа №4
## Хеш-функции (SHA-256)

### Цель работы
Изучить принципы работы криптографических хеш-функций и реализовать механизм проверки целостности файлов.
### Задачи
- Вычисление хеша файла.
- Сохранение контрольной суммы.
- Проверка целостности файла.
- Сравнение текущего и сохранённого хеша (демонстрация лавинного эффекта).

### Программа испольщует
- Python 3
- hashlib (SHA-256)
- PyQt6 (графический интерфейс)
- argparse (командная строка)
- unittest (тестирование)

### Структура проекта
- `hash.py` - функции хеширования
- `cli.py` - командная строка
- `gui.py` - графический интерфейс
- `test_hash.py` - юнит-тесты
- `text.txt` - исходный текст 
- `hash.sha256` - итоговый хеш


### Результаты
- Все тесты пройдены (5/5)
- Программа поддерживает CLI и GUI
- Лавинный эффект подтверждён экспериментально

### Вывод
SHA-256 является надёжной хеш-функцией: даже малое изменение входных данных приводит к кардинальному изменению хеша.
